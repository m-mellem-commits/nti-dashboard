# Norwegian Team India – World's Toughest Row 2026

Dashboard for å følge Norwegian Team India over Atlanterhavet (La Gomera → Antigua, start 12.12.2026).

Se siden: https://m-mellem-commits.github.io/nti-dashboard/

- `index.html` – selve dashboardet (alt innbakt, fungerer også som enkeltfil)
- `data.json` – posisjon, vær, flåte og nyheter (oppdateres automatisk hver 6. time)
- `team.jpg`, `latest-post.jpg` – toppbilde og siste Instagram-innlegg
